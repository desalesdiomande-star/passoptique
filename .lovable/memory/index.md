MTN-branded SaaS for opticians (PASS OPTIQUE by MTN). Yellow #FFCB05 primary, black sidebar, MTN Brighter Sans font.

## Design System
- Primary: HSL 49 100% 51% (MTN yellow #FFCB05)
- Foreground/Sidebar bg: HSL 0 0% 0% (black)
- Background: HSL 220 20% 97% (light gray #F5F6F8)
- Card: white
- Font: MTN Brighter Sans (woff2 in /public/fonts/)
- Currency: FCFA
- Bilingual: fr/en

## Roles
- superadmin (platform-level, manages all cabinets, maintenance, platform settings)
- admin (shop admin, full access within a cabinet)
- directeur (director, sees everything except admin-level user mgmt)
- vendeur (seller, sales/clients/stock/prescriptions/invoices)
- caissier (cashier, payments/reports only)
